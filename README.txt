SPARKELO — beauty studio portfolio website

КАК ЗАПУСТИТЬ:
1. Распакуй ZIP.
2. Открой index.html в браузере — сайт уже работает локально.
3. Для публикации загрузи index.html, style.css и script.js в одну папку на хостинге (обычно public_html).

ОБЯЗАТЕЛЬНО НАСТРОЙ WHATSAPP:
Открой script.js и замени:
const WHATSAPP_NUMBER = "77777777777";
сейчас установлен тестовый номер +7 777 777-77-77. Замени его на свой реальный номер перед публикацией.
Например, Казахстан: 77011234567.

ПРИМЕЧАНИЕ:
Сайт — демонстрационный концепт для портфолио. Цены, отзывы, тексты и визуальные карточки вымышлены; замени их на реальные данные и фотографии перед коммерческим использованием.
Google Fonts загружаются из интернета. Если шрифты недоступны, сайт использует системные fallback-шрифты.
